# <span style="color: orange">Experiment Tracking</span>

#### Directory Structure

Everytime you train a model.... an experiment folder is built (except if training was resumed, thereby it is used the folder of the prior run)... the global configuration file is stored in the experiment folder to fetch the original parameters during training resume... experiments folder contains logs and settings from prior runs, useful to resume training or evaluate checkpoints. Encompasses configuration files, trained weights, logs, figures, and predictions.

the structure is the following....

```
├───experiments
      ├───voxrdiff
      │      ├───example_experiment_01
      │      │      ├───checkpoints
      │      │      │      └──1.pth
      │      │      │      └──2.pth
      │      │      │      └──3.pth
      │      │      ...    └──...
      │      │      │
      │      │      ├───configs
      │      │      │      └──config.yaml
      │      │      │
      │      │      ├───figures
      │      │      │      ├───test
      │      │      │      └───train
      │      │      │
      │      │      ├───logs
      │      │      │      ├───test
      │      │      │      └───train
      │      │      │
      │      │      └───results
      │      │      │      └──example_result_0001.nii.gz
```

#### Folder Description

`configs` ... contains copy of global configuration file used in the experiment. Loaded in case of training resuming.

`checkpoints` ... contains saved checkpoints of the model during training

`figures` ....

`logs` ....

`results` ... contains the output of running the trained model on the test set. The results are typically generated by running the trained model on the test set using the test.py script.
